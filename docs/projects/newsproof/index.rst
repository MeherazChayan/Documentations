NewsProof
=========

A web application and Chrome extension for examining evidence and provenance associated with news content. It supports URL, text, image, audio and video inputs, with different processing capabilities for each format.

**Source repository:** `NewsProof <https://github.com/MeherazChayan/NewsProof>`_ (public project repository).
