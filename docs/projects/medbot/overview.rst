Prototype scope and sensor behavior
===================================

MedBot Assist is an educational miniature prototype. It combines four-wheel
motor behavior with an ultrasonic scanning system, analog light measurement
and a rain sensor coupled to a small umbrella servo.

The published project material describes three demonstrated behaviors:

- Ultrasonic sensing used for simple obstacle avoidance.
- Light measurements that can trigger a programmed motor stop.
- Rain detection that controls a miniature umbrella servo.

The repository includes an Arduino sketch, a hardware photograph, a schematic,
a research-style report and an illustrated user manual.

Safety boundary
---------------

The prototype **cannot carry people** and is not a certified wheelchair,
stretcher or medical device. It lacks a patient-carrying frame, validated
braking, redundant sensing and a verified emergency-stop mechanism. It must
not be used to transport a person or to perform medical care.

The public README states that the code had not been hardware-tested as part of
its repository revision. Do not interpret the repository as evidence of
validated real-world mobility performance.
