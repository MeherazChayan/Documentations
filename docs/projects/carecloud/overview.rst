Product scope and architecture
==============================

Care Cloud is described by its public repository as a full-stack healthcare
MVP built with the MERN stack. The repository contains separate ``frontend/``
and ``backend/`` directories, with a root Node package manifest.

The product description covers discovering doctors, viewing availability,
requesting online or in-person consultations, and broader areas for medical
records, payments and a health-awareness community.

The repository provides a public deployment link. The presence of the link or
a described feature does not establish that every workflow has been
successfully tested or operates with production-grade privacy and security.

As a healthcare-related application, example accounts and test data should be
used during review; do not upload real patient information to an environment
without independently confirmed privacy, security and operational safeguards.
