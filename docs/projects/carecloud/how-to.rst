Explore the published application
=================================

The repository links to `Care Cloud on Vercel <https://care-cloud-two.vercel.app/>`_.

A reader evaluating its interface can use the feature descriptions as a guide:

1. Inspect doctor discovery and availability information.
2. Examine how the interface represents online and in-person consultations.
3. Review the presentation of medical-record, payment and community areas
   where visible in the current deployment.

The live website was not functionally tested for this documentation build;
these are areas to inspect, not assertions that every operation will succeed.

Developer setup
---------------

The public repository exposes ``frontend/``, ``backend/`` and package
manifests. Exact environment variables, startup scripts and database setup
cannot be determined reliably from the visible README alone. Consult the
actual manifest and backend configuration before following or publishing a
complete installation guide.

No installation command is supplied here because guessing one would be
misleading for a full-stack application with external dependencies.
