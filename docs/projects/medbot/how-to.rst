Review the original prototype materials
=======================================

Understand the design
---------------------

1. Read the `user manual <https://github.com/MeherazChayan/MedBot-Assist/blob/main/docs/User_Manual.pdf>`_ before handling the hardware.
2. Review the `hardware schematic <https://github.com/MeherazChayan/MedBot-Assist/blob/main/images/schematic.png>`_ to identify connected components.
3. Inspect the `Arduino sketch <https://github.com/MeherazChayan/MedBot-Assist/blob/main/src/project_CSE461.ino>`_ for exact sensor and actuator logic.
4. Use the `demonstration and project overview <https://github.com/MeherazChayan/MedBot-Assist#demonstration-video>`_ to understand the scale of the prototype.

Before attempting to reproduce the hardware
-------------------------------------------

The repository README does not itself supply a verified, complete bill of
materials, pin-by-pin wiring procedure, power specification or validated
hardware acceptance test. Consult the schematic, manual and actual sketch
before connecting hardware. Do not improvise electrical connections based on
this overview.

The original documentation is a better source of exact operating steps than
an inferred setup sequence. A complete, independently validated assembly
tutorial has not been produced in this documentation collection.
