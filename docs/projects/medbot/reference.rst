Demonstrated capabilities
-------------------------

``Ultrasonic obstacle detection``
   Used for basic navigation/avoidance behavior.

``Light measurement``
   Analog input can lead to a programmed motor stop.

``Rain-triggered actuation``
   Rain input controls a miniature servo-operated umbrella.

Safety and validation
---------------------

This is not a patient-rated machine. The project README reports no verified
emergency stop, certified brakes, redundant sensing or safety-rated mobility
operation. No field-use or human-transport instructions are provided here.
